# 名称
fcitx5-vinput - Fcitx5 语音输入架构总览与概念说明

# 描述
**fcitx5-vinput** 是为 Linux 桌面 Fcitx5 输入法框架打造的离线/云端双模语音输入生态。它将系统级音频采集、本地与远程语音识别（ASR）以及大语言模型（LLM）后处理润色有机结合，为桌面环境提供流畅高效的语音打字体验。

# 默认快捷键

快捷键可在 Fcitx5 配置 → 附加组件 → Vinput 中自定义：

**Alt_R**（触发键）
:   轻按（Tap）开始录音，再次轻按结束录音并识别；长按（Hold）按住说话，松开即识别。

**Control_R**（指令键）
:   在任意窗口选中文本后长按此键说话，可通过语音指令让大模型直接修改选中的文字。

**Shift_R**（命令面板键）
:   即时弹出统一命令面板（Command Palette），作为常用快捷操作统一入口，支持全局盲打搜索与命令过滤：`/model`（`/m`）切换划词指令大模型、`/asr`（`/a`）切换 ASR 引擎与模型、`/scene`（`/s`）切换听写场景、`/proc`（`/p`）启停本地适配器进程。

**Page Up** / **Page Down**, **↑** / **↓**, **1**-**9**
:   翻页、移动光标及快捷选择候选词。

# 语音输入处理流

1. **音频采集**：从选定的 PipeWire 麦克风输入节点捕获高品质音频；
2. **VAD 裁剪**：自动剔除首尾静音片段，减少识别耗时；
3. **ASR 识别**：由本地 sherpa-onnx 模型（完全离线）或云端服务商脚本转写为文本；
4. **场景润色**：若激活了润色场景，通过 LLM 纠正同音错别字、补充标点或进行翻译；
5. **文字上屏**：在 Fcitx5 候选框中展示识别候选，确认后直接输入到当前焦点窗口。
